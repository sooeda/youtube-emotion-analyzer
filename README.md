# Описание проекта
YouTube Emotion analyzer - учебно-исследовательский проект, посвящённый многометочной классификации эмоций в русскоязычных комментариях YouTube.

В проекте исследуются методы для мультилейблового анализа тональности. Предобработка включает очистку текста, обработку эмодзи, удаление стоп-слов (с помощью NLTK) и лемматизацию с использованием Natasha. 

Для классификации используются рекуррентные нейронные сети LSTM и BiLSTM. Сравниваются два подхода:

1) Базовый - единая модель для предсказания всех эмоций.

2) Подход с маршрутизацией - отдельная модель распределяет тексты между специализированными моделями для примеров с одной и несколькими эмоциями.

Подбор гиперпараметров выполняется с помощью Keras Tuner (Random Search). Исследуются тип архитектуры, количество нейронов и параметры Dropout. Качество моделей оценивается с использованием Micro-F1, Macro-F1, Precision и Recall. При запуске обучения автоматически скачивается набор данных https://huggingface.co/datasets/Djacon/ru-izard-emotions. 

# Структура проекта

src/emotion_app/training.py — обучение моделей и проведение экспериментов.

templates/ — шаблоны веб-интерфейса.

app.py — Flask-приложение.
